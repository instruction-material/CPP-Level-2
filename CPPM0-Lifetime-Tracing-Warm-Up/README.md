# CPPM0 Project 1: Lifetime Tracing Warm-Up

Trace stack frames, copies, references, and lifetime boundaries before writing
larger pointer-heavy code.

Practice goals:
- distinguish pass-by-value from pass-by-reference
- identify `const` reference observation
- explain why a local variable stops being usable when its scope ends
- use printed addresses as evidence, not as a replacement for reasoning

Student extension:
- draw the stack frame diagram before running the code, then correct it after
  comparing your prediction with the output.
