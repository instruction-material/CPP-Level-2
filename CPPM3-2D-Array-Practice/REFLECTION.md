# Reference reflection after an attempt

The observer pointer describes one real flat array; the sample driver no longer
casts a nested array to that type. Shape and capacity remain caller obligations.
The sum checks every ordered int prefix before addition. Minimum rejects empty
input before reading. Averages accumulate and divide in floating point and
return the doubles requested by the original fourth task. The raw-pointer table
has value-initialized row slots so partial allocation failure can release only
live rows and then its outer owner. The driver deletes each completed table and
average allocation exactly once. Explain these boundaries on a new rectangle
before considering the optional column-statistic extension.
